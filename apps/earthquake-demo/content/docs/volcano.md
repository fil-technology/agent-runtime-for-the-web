# Volcano alert levels

Ground-based alert levels run **normal**, **advisory**, **watch**, **warning**.
Aviation colour codes run **green**, **yellow**, **orange**, **red**, and
describe hazard to aircraft from ash.

A volcano can be at aviation orange while the ground alert stays at watch: the
codes describe different hazards to different audiences. Alert levels are set
by the responsible observatory and change without warning.
