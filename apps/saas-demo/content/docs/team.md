# Team and access

## Inviting people

Go to **Settings → Team** and choose **Invite**. Invitations are sent by email
and expire after seven days. You can invite someone as a *member* or as an
*admin*.

## Roles

Members can create and manage their own projects. Admins can additionally
manage billing, invite and remove people, and cancel the subscription.

## API keys

API keys live under **Settings → API keys**. Keys are scoped to a single
project and are shown once at creation time. If you lose a key, revoke it and
create a new one.
